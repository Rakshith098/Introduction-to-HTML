Structure of HTML

HTML stands for HyperText Markup Language
It is used to create Webpages for people to interact
HTML contains elements to make these Webpages. Here are some
1. html- This element contains all other elements
2. head- It holds the elements which cannot be seen by the user
3. body- This tag show the content written to the user
# Elements used in head tag-
1. title- It shows the document
# Elements used in body tag-
1. h1- This tag is used to give the text as a heading
2. p- This tag is used to write this text as a paragraph
3. br- this tag is used to break between lines in the paragraph
Comment tag is also used when making a webpage but it is not a part of the program. This tag is useful to make it easier for others to understand the code
